# Bank Management System (Java & OOPs)

A console-based Bank Management System built in Java demonstrating Object-Oriented Programming (OOP) concepts and data handling using Java Collections.

## 🚀 Features
* **Account Creation:** Support for Savings Accounts (with interest calculations) and Checking Accounts (with overdraft protection).
* **Core Banking Operations:** Deposit, Withdrawal, and Instant Fund Transfer between accounts.
* **Transaction Logs:** Detailed transaction history tracking per account.
* **Menu-Driven CLI:** User-friendly interactive console interface.

## 🛠️ Concepts Demonstrated
* **Encapsulation:** Private variables with public getter/setter methods.
* **Inheritance:** Base `Account` class extended by `SavingsAccount` and `CheckingAccount`.
* **Polymorphism:** Method overriding for tailored financial operations and rules.
* **Abstraction:** Abstract methods enforcing standard account behavior.
* **Collections Framework:** Data handling using `HashMap` and `ArrayList`.
